# Printable bracket and embedded fonts — 29 October 2026

Staging source/assets only. No database, production or store deployment changes.

The competition print action now offers:

- Readable A4 landscape sections: for the 45-entry championship, four quarter sections plus a finals page. Larger brackets paginate recursively into readable branches rather than shrinking every name to fit one page.
- Whole-draw A3 landscape: one sheet for up to 64 entrants. Larger draws must use A4 sections; the chooser disables the compact option to prevent overlapping boxes.

Rounds run left to right; match positions remain top to bottom in the supplied order. Two player rows per match, connector lines to the correct destination side, stable references (P1, R32-7, QF2, SF1, F1), round deadlines and recorded scores. Unresolved participants use Winner of <reference>. A player advancing without a preliminary match appears directly in the next round. No explicit bye box or bye label is printed. Empty preliminary columns on the lower quarter sections are omitted. The finals sheet repeats quarter-final match references so it can be followed independently alongside the branch sheets.

New `competition_bracket_pdf.dart` provides the generator; `competition_draw_pdf.dart` exports it to preserve existing callers. The App printer request uses the selected paper size. Existing screen listing and date storage are unchanged.

Fonts: Noto Sans Regular and Bold are bundled in assets/fonts, registered as assets and embedded through the PDF document theme (also supplied for italic/boldItalic styles). No runtime font download or use of Windows system fonts. OFL licence included as assets/fonts/OFL.txt. Removes the previous Helvetica/Unicode/en-dash warnings while retaining real Unicode names/punctuation.

## Optional rules box and preview

All three formats now offer Print competition rules, off by default. A bordered box uses saved competition rules (or scoring when rules are empty) in the top-right header, outside the bracket. Header space is reserved so the draw cannot overlap it. It appears on every section page. The control is disabled when no rules/scoring exist.

Print options now lead to an on-screen PdfPreview with Print and Save/Share actions. The generated PDF bytes are reused for preview and output, preserving selected orientation, background, blank winner labels and rules. No print dialog is launched merely by opening the preview.

## Printer paper-size correction

The preview previously returned fixed PDF bytes when the Windows print callback requested the printer's actual paper dimensions. The printing plugin renders at PDF size without automatic fitting, so an A3 PDF sent to A4 could clip. PdfPreview now rebuilds using the requested paper dimensions and reserves at least the printer's reported hardware margins. Format, rules, background and winner-label settings are retained. Preview title shows the requested paper and orientation.

Validated with 25 passing competition tests and clean analysis. An A3-layout request with A4 printer dimensions and asymmetric margins generated a genuine A4 PDF with the rules retained; rendered and inspected. Physical printer output still requires user verification. No production/database/store change.
